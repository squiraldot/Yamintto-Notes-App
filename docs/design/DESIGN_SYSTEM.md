# Design system

Current app uses Material 3 seeded light (#5267D8) and dark (#9AA8FF) schemes; these are starter defaults, not approved brand tokens. Phase 01 establishes the initial app-shell tokens. Phase 09 owns final UI/UX polish and user-selectable theme/font preferences and persistence. Palette, typography, spacing, radii, elevations, icons, components and AMOLED near-black values remain undecided; do not invent final visual design. Centralize semantic tokens and test contrast, accessibility, Markdown readability and platform system bars.
