# Accessibility

Phase 09 owns the cross-app accessibility audit and persisted font preferences. Phase 03 editor/viewer requirements are implemented in source and covered by widget tests: labeled title/source fields, selectable preview content, semantic Markdown headings, task checkbox labels, editor/preview mode controls, live save-status semantics, error/retry states and text-scaling behavior. Keyboard input, native text selection and copy/paste use Flutter TextField/SelectableText controls. Links are currently styled but inert; image nodes expose alt-text placeholders. Owner physical-device TalkBack/VoiceOver, hardware-keyboard/focus traversal, touch-target and contrast verification remain pending. No full-app accessibility audit is claimed.
