# Theming

Current implementation: `ThemeMode.system` with Material 3 seeded light and dark ThemeData. No user preference persistence and no AMOLED mode exist.

Ownership: Phase 01 establishes initial design tokens and app-shell theme foundation. Phase 09 implements user-selectable system/light/dark/AMOLED preference and persistence through settings. Final palettes and AMOLED surfaces require design approval. Test contrast, focus, disabled, selected, error/destructive states, system bars and restart persistence.
