# PRODUCT_OVERVIEW

Yamintto is an independent offline-first Flutter notes app for Android/iOS. It aims to provide folders, Markdown notes, productivity tools, encryption, recovery, biometrics, and portable backups. Current app is only a foundation shell. YRNotes is a separate web app and must remain untouched. Legacy ZIP import is a goal, not verified compatibility; inspect its source and real fixtures first. Principles: offline-first, local ownership, transactional data integrity, reviewed encryption, explicit recovery limits, native adapters, phase-gated development.
