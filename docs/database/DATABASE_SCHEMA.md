# DATABASE_SCHEMA

Drift/SQLite packages are configured, but no database class, table declarations, generated code, schema version or migrations exist. Proposed schema only: folders(id PK,parent_id self-FK,name,timestamps,order); notes(id PK,folder_id FK,title,content payload,timestamps,pinned,format version); note_tags(note/tag association); attachments(id,note_id FK,metadata,encrypted blob ref); note_revisions(id,note_id FK,encrypted snapshot,time); app_settings(key,value,type/version); encryption_metadata(format/KDF/wrapped-key metadata only); trash_items(entity type/ID,deleted time,original location). Proposed indexes: folders(parent_id), notes(folder_id,updated_at,pinned), note_tags(tag,note_id), attachments(note_id), revisions(note_id,time), trash(deleted_at). Use transactions for folder moves, delete/restore, revisions and backup snapshots. Exact IDs, tag model, deletion policy, encrypted search, content representation and FKs remain open. Never let proposal override actual future Drift schema.
